Your dashboard for tracking and analyzing your study earnings. Let's set up your workspace in less than a minute!

What's New

Changelog

v3.1
2026-06-01 ▼
  • Study Editing: You can now edit all details of past entries (Study Name, Date, Pay, Bonus, Time, Status).
  • Manual Logging Status: Manual entry now lets you select the study's approval status directly from a dropdown before adding.
  • CSV Export Fixes: Resolved a bug where exporting to CSV threw a ReferenceError, and redesigned the export filename format to now include the active period (e.g. Mar-2026-EarnTrack-2026-06-01.csv) for better clarity.
  • Automatic Updates: Improved the offline mode so the app now automatically stays up-to-date and loads new versions without requiring a manual hard refresh.
v3.0
2026-05-29 ▼
  • What's New Dialog: Added this very dialog — the one you're reading right now. Meta, we know.
  • Initial Setup & OOBE Wizard: Added a friendly Out-Of-Box Experience (OOBE) setup wizard that guides first-time users through configuring their preferred display currency, time format, start of the week, setting an optional weekly goal, and importing their very first CSV file to get started immediately.
  • Mobile Optimized UI: Overhauled the layout for touch devices by introducing a bottom navigation bar and adjusting card padding for consistent presentation across diverse screen sizes.
  • Progressive Web App (PWA) Support: Added comprehensive PWA capabilities with a service worker for offline caching of app resources, modern custom app icons, and install configurations so the site can be installed and launched offline.
  • Unified Dashboard & Chart Range Selector: Replaced the separate chart range tabs with automatic synchronization: switching dashboard periods (Week, Month, Year, All time) now automatically adjusts the earnings chart view to matching granularities (7-day Daily, 12-month selected Year, All-Time Yearly), simplifying navigation and decluttering the layout.
  • Bitcoin Currency Support: Added Bitcoin (BTC) as a display currency option, complete with live exchange rates and high-precision decimal formatting.
  • Thousands Separator: Large monetary and numeric values now display commas for much easier readability.
  • Improved Time Metrics: The "Time Spent" metric card now displays elapsed days when applicable.
  • 12/24 Hour Format & Hover Tooltips: Added configurable 12-hour and 24-hour time formats, and hovering over a study's date now reveals the exact full timestamp.
  • Redesigned Manual Entry: Upgraded the manual entry form with a custom Material 3-inspired date/time picker, and fixed the bonus currency label to correctly match the selected currency.
  • Start of Week Selector: Added a Start of Week selector to adjust the charts, studies list, stat calculation, etc. based on what day of the week your work week starts on.
  • Categorized Settings Modal: Categorized the settings modal to group related configuration options.
  • Manual Currency Rate Refresh: Added a Refresh button in the Currency settings to force-update the cached exchange rates immediately without waiting for the 6-hour cache to expire.
  • Refined Chart Visuals: Corrected chart bar rounding so that bars are flat on the bottom and rounded on top.
  • Accent Color Picker Fix: Fixed a layout issue where the rainbow icon for custom accent color selection was getting clipped.
  • Status Totals Alignment: Fixed status count and amount alignment in the status totals grid to ensure columns align perfectly even when a status label wraps to multiple lines.
  • Consistent Metric Card Layout: Improved responsive styling to ensure core metric card sizes (e.g. Total Earned, Time Spent) remain consistent and proportional across mobile and desktop devices.
  • CloudResearch Import Date Fix: Resolved an issue where CloudResearch imports failed to capture the correct date and time due to the export file containing dynamic timezone-specific column names.
v2.0
2026-05-24 ▼
  • CloudResearch CSV Support: Import CloudResearch CSV files! No longer only supports Prolific.
  • Redesigned UI: Completely overhauled UI with the addition of Light/Dark Mode, Accent Colors, better use of widescreen, and more.
  • Stacked Earnings Chart: Earnings chart now displays Pending (Awaiting Review) surveys stacked in a dynamic secondary color on top of Approved.
  • Custom Minimum Wage Configuration: Directly configure your minimum wage in your local currency. Study rate badges color coding now based on your minimum wage.
  • Status Totals: Added total status counts (Approved, Awaiting Review, Screened Out, Rejected, etc.) to the dashboard..
